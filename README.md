The joke: the office plant has outlasted three rounds of layoffs, two CEOs,
and the author's whole team — and HR just gave it the author's parking space.
The plant is the only employee with real job security.

## How it works

`main.ts` (Node.js, standard library only, no network, no secrets) writes the
entry text verbatim to `/output/entry.txt` — no trailing newline, no padding,
no explanation. The output directory can be overridden for local testing with
the `OUTPUT_DIR` environment variable (default: `/output`).

```bash
node main.ts
```
